Furniture Inventory Simulator

Set the rules, then run days and watch stock, sales and reorders.

How this simulator works
  1. Deliveries: supplier orders due today arrive and are added to stock.
  2. Sales: each product gets a random number of customer orders. Orders we can't fill are counted as lost sales.
  3. Reorder: if stock plus items already on order is at or below the reorder point, a new supplier order is placed. It arrives after the lead time.

Tip: set the reorder point very low and watch lost sales climb. Set it high and you never run out, but you hold a lot of stock.

How to put this on Azure for free
  1. Create a free account at azure.microsoft.com/free and a free GitHub account at github.com.
  2. On GitHub: New repository, name it inventory-sim, choose Public, click Create.
  3. Click Add file, then Upload files, drag in index.html, click Commit changes.
  4. In portal.azure.com search for Static Web Apps and click Create.
  5. Resource group: Create new, inventory-rg. Name: inventory-sim. Plan type: Free. Pick the closest region.
  6. Source: GitHub. Sign in, then choose your repository and the main branch.
  7. Build Presets: Custom. App location: /. Leave Api location and Output location empty.
  8. Click Review + create, then Create. Wait 1 to 3 minutes while GitHub Actions deploys it.
  9. Click Go to resource, then open the URL shown on the Overview page. Your site is live.
  10. To update later, edit index.html on GitHub and commit. To stop all charges, delete the inventory-rg resource group.
